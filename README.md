## Project Description and Purpose

It is a web-based OJT Attendance Tracking System designed to help CICS students of Zamboanga Peninsula Polytechnic State University (ZPPSU) record and monitor their attendance during On-the-Job Training. It aims to provide an organized way of managing attendance, verifying trainee identity, calculating rendered hours, and reducing manual recording errors.

## Key Features

- Trainee Registration and Login
- Administrator Login
- Face Biometric Verification
- Time In and Time Out
- Automatic Rendered Hours Calculation
- Attendance Monitoring
- Trainee Management
- Attendance Reports

## User Roles

### Trainee

- Register and log in.
- Record Time In and Time Out.
- Verify identity through face biometrics.
- View attendance records and rendered hours.

### Administrator

- Manage trainee accounts.
- Monitor and review attendance.
- Generate attendance reports.

## Technology Stack

- Frontend: ReactJS
- Backend: PHP (Laravel)
- Database: MySQL
- Face Verification: Face Biometric API

## Project Scope and Limitations

It focuses on CICS students of ZPPSU taking OJT. It covers trainee registration, identity verification, attendance recording, rendered hours calculation, and attendance monitoring. The system depends on available camera and biometric verification services.
